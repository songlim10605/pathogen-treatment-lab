# 감염 및 치료 기전 비교 시뮬레이션

세균·바이러스·프리온의 질병 발생 과정과 치료 표적 차이를 비교하는 교육용 앱입니다.

## 실행

```bash
py -m pip install -r requirements.txt
py -m streamlit run app.py
```

명령이 작동하지 않으면 `py` 대신 `python`을 사용하세요.

## 파일 역할

- `app.py`: Streamlit 앱을 실행하고 웹 애니메이션을 불러옵니다.
- `web/index.html`: 앱의 화면 구조입니다.
- `web/*.css`: 화면 색상과 배치를 담당합니다.
- `web/*.js`: 감염·치료 애니메이션과 가상실험을 담당합니다.
- `실행방법.txt`: Windows 노트북용 단계별 안내입니다.

## 과학적 한계

대표적인 기전을 단순화한 교육용 디지털 모델입니다. 그래프의 값은 상대지수이며 실제 환자의 진단·처방·약효·예후를 예측하지 않습니다. 프리온의 구조 전환 억제 및 제거 촉진은 탐구를 위한 가상 가정이며 확립된 치료법으로 제시하지 않습니다.
